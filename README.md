# Google-Photo-Uploader

Google 포토에 올리기 전에 사진·동영상을 **100개씩 폴더로 나누고 이름을 정리**하는 Windows 앱입니다.

## 받기

[Releases → Google-Photo-Uploader (main)](https://github.com/woodgh/Google-Photo-Uploader/releases/tag/uploader-main)에서
`Google-Photo-Uploader-<날짜>-<빌드>.zip`을 받아 압축을 풀고 `Google-Photo-Uploader.exe`를 실행합니다. (설치 없음)
서명되지 않은 실행 파일이라 SmartScreen 경고가 뜨면 [추가 정보] → [실행]을 누르세요.

## 사용법

1. 정리할 폴더 여러 개를 창에 **끌어다 놓거나** [폴더 추가...]로 고릅니다. (하위 폴더까지 모두 포함)
2. 필요하면 [변경...]으로 **저장 폴더**를 바꿉니다. 기본값은 `사진\Google-Photo-Uploader`이며 다음 실행 때도 기억합니다.
3. [완료]를 누르면 정리가 끝난 뒤 결과 폴더가 열립니다.

## 결과

```
<저장 폴더>\2026-10-06_22-30-15\      ← 실행 시각
    001\2019_07_14_09_3fa2c81d.jpg     ← 100개
    002\...                            ← 100개
    003\2024_05_01_13_ab12cd34.mp4     ← 나머지
```

- 파일은 **이동**됩니다(복사 아님). 원본 폴더 구조는 남고 사진·동영상만 빠집니다.
- 이름: `년_월_일_시_해쉬.확장자`
  - 시각: 사진은 EXIF 촬영 시각, 동영상은 촬영(인코딩) 시각, 없으면 파일 수정 시각 (내 PC 시간대 기준)
  - 해쉬: 파일 내용 SHA-256의 앞 8자리. 같은 이름이 이미 있으면 `_2`, `_3`을 붙입니다.
- 오래된 파일부터 `001` 폴더에 들어갑니다.
- 사진·동영상(jpg, png, heic, raw, mp4, mov 등)만 옮기고 다른 파일은 제자리에 둡니다.

## ② Pixel 폰으로 업로드

정리한 폴더를 묶음 단위로 Pixel 폰에 넣어 Google 포토가 백업하게 하고, 끝나면 다음 묶음을 넣습니다.

**처음 한 번 준비**
1. 폰: 설정 → 휴대전화 정보 → 빌드 번호 7번 탭 → 개발자 옵션 → **USB 디버깅** 켜기
2. USB로 연결하고 폰 화면의 **USB 디버깅 허용**을 누릅니다 (이 컴퓨터 항상 허용 체크)
3. Google 포토 앱에서 백업을 켜 둡니다. (충전 중에만 백업 / Wi-Fi 설정에 따라 대기할 수 있습니다)

화면 ② 영역의 폰 상태에 `연결됨: Pixel ...`이 보이면 준비가 끝난 것입니다. adb는 zip에 들어 있어 따로 설치하지 않아도 됩니다.

**사용법**
1. 업로드 폴더: ①에서 정리하면 자동으로 채워집니다. 다른 폴더는 [변경...]으로 고릅니다. (`001`, `002`… 가 들어 있는 폴더)
2. 방식: **슬로우 (1개씩)** 로 먼저 잘 되는지 확인한 뒤 50개씩 / 100개씩으로 바꿉니다.
3. 완료 폴더: 업로드가 끝난 PC 파일을 옮길 폴더. [변경...]으로 고르면 `<완료 폴더>\<정리 폴더 이름>\NNN\`으로 옮기고(다른 드라이브여도 날짜 보존), [기본]이면 정리 폴더 안 `업로드 완료\NNN\`.
4. 변동 없음(분): 이 시간 동안 Google 포토 알림에 변동이 없으면 업로드 완료로 봅니다. 기본 슬로우 3분, 50/100개 30분.
5. [업로드 시작]

**동작**
1. 묶음을 폰 `DCIM/Camera`에 복사하고 갤러리에 등록합니다. (수정 시각 보존)
2. Google 포토 알림을 지켜봅니다. 백업 중 알림이 있거나 알림 내용이 바뀌면 처음부터 다시 셉니다.
3. 백업 중이 아니고 정한 시간 동안 변동이 없으면 → PC 파일을 완료 폴더로 옮기고, 폰 사본을 지웁니다.
4. 다음 묶음으로. 진행 기록은 화면 로그와 `<정리 폴더>\upload-log.txt`에 남습니다.

- [중지]하거나 앱을 꺼도 폰에 넣은 묶음은 그대로 둡니다. 다시 [업로드 시작]하면 폰에 남은 파일부터 이어서 확인합니다.
- 폰 연결이 끊기면 기다렸다가, 다시 연결되면 변동 없음 시간을 처음부터 다시 셉니다.
- 폰에서 지우는 건 이 앱이 넣은 파일뿐입니다. 폰에서 지워도 Google 포토에 올라간 사진은 지워지지 않습니다.
- 완료 판정은 알림을 보고 추정하는 방식입니다 (Google 포토는 백업 상태를 알려 주는 API가 없음). PC 원본은 완료 폴더에 남으니 Google 포토에서 확인 후 정리하세요.

## 빌드

Visual Studio 2022 + CMake 3.24 이상:

```
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release
```

main에 push하면 GitHub Actions가 빌드·테스트 후 Release `uploader-main`의 zip을 최신 빌드로 바꿉니다.
